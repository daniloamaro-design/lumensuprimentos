Tipo de Compra —

Defina como as compras desta casa são realizadas. Esta configuração é usada no orçamento financeiro.

Compra Direta: A equipe de Fortaleza realiza a cotação com fornecedores e compra os produtos para esta casa.
Transferência Financeira: É realizada uma transferência do valor do orçamento para o coordenador desta casa, que realiza a compra localmente.
