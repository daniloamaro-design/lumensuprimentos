1️⃣ Upload dos arquivos

Coloque os arquivos na mesma pasta
Os arquivos lumen-rbac.js e lumen-bi.js precisam estar na mesma pasta que o seu index.html. Se você usa o Firebase Hosting, suba os 3 arquivos juntos.
Faça o deploy dos novos arquivos
Se você usa Firebase Hosting (URL do tipo seu-projeto.web.app), execute no terminal:

firebase deploy --only hosting

Se ainda não usa Firebase Hosting, basta copiar os 3 arquivos para onde está o index.html no seu servidor.

2️⃣ Editar o index.html (4 linhas)

⚠️
Faça um backup do seu index.html antes de editar. Renomeie uma cópia para index-backup.html.
Adicione as 2 linhas antes do </body>
Abra o index.html em qualquer editor de texto. Procure a linha que diz </body> (está quase no final do arquivo, linha ~12741). Cole as linhas abaixo logo antes dela:
<script src="lumen-rbac.js"></script>
<script src="lumen-bi.js"></script>
Adicione a chamada ao RBAC no onAuthStateChanged
No seu index.html, procure por onAuthStateChanged. Você vai encontrar algo parecido com isso:
// código que já existe no seu arquivo
firebase.auth().onAuthStateChanged(async (user) => {
  if (user) {
    // ... carregamento de dados do usuário ...
    currentUserData = snap.data();
    // ... mais código ...
  }
});
Logo depois de currentUserData = snap.data();, adicione esta linha:
await inicializarRBAC(user.uid); // ← ADICIONE ESTA LINHA
Adicione o registro de login
Na mesma função, logo após a linha que você acabou de adicionar, cole:
registrarAuditoria('login', `Login realizado com sucesso`);
Registre o logout também
Procure a função doLogout() no seu arquivo. Antes do firebase.auth().signOut(), adicione:
await registrarAuditoria('logout', 'Logout realizado');
await firebase.auth().signOut();

3️⃣ Regras de Segurança do Firestore

🔴
Esta etapa é importante! Sem as regras corretas, qualquer pessoa poderia acessar ou deletar dados do seu banco. Leva apenas 3 minutos.
Acesse o Firebase Console
1. Abra o navegador e acesse: https://console.firebase.google.com
2. Clique no seu projeto (ex: "lumen-estoque" ou o nome do seu projeto)
3. No menu lateral esquerdo, clique em Firestore Database
4. Clique na aba Regras (está na barra superior, ao lado de "Dados")
Cole as regras do arquivo firestore.rules
1. Abra o arquivo firestore.rules que você recebeu em qualquer editor de texto
2. Selecione todo o conteúdo (Ctrl+A) e copie (Ctrl+C)
3. De volta no Firebase Console, apague todo o conteúdo que está na caixa de Regras
4. Cole o conteúdo que você copiou (Ctrl+V)
5. Clique no botão azul "Publicar"
6. Aguarde a mensagem de confirmação
✅
Pronto! O Firestore agora vai verificar o perfil de cada usuário antes de permitir qualquer acesso.

4️⃣ Criar perfis dos usuários no Firestore

Perfis disponíveis
O sistema tem 5 perfis. Escolha um para cada usuário:
PerfilO que pode fazer
adminAcesso total, gerencia usuários, vê audit log
compradorCria pedidos, aprova, edita financeiro, fornecedores
gestorVisualiza e aprova, sem editar dados-mestre
solicitanteSó cria e acompanha os próprios pedidos
viewerSó visualiza, sem criar nem editar
Encontre o UID de cada usuário
1. No Firebase Console, vá em Authentication (menu lateral)
2. Clique na aba Users
3. Você vai ver uma lista de e-mails. Para cada usuário, copie o valor da coluna User UID (é uma sequência longa de letras e números, ex: xK3mR9pQwZ...)
Crie um documento de perfil para cada usuário
1. No Firebase Console, vá em Firestore Database
2. Clique em + Iniciar coleção
3. No campo "ID da coleção", digite: usuarios_perfis e clique em Avançar
4. No campo "ID do documento", cole o UID do usuário que você copiou
5. Adicione o campo: 
Campo:  perfil
Tipo:   string
Valor:  admin   (ou comprador, gestor, solicitante, viewer)
6. Clique em Salvar
7. Repita para cada usuário, clicando em + Adicionar documento dentro da coleção usuarios_perfis

6️⃣ Registrar ações no código existente

Adicione o registro em cada ação importante
Em cada função abaixo, adicione a linha correspondente logo após a ação ser salva com sucesso no Firestore:
Função no index.htmlLinha a adicionar (após sucesso)
submitOrder() ou ao criar pedido registrarAuditoria('criar_pedido', `Pedido ${code} criado para ${house}`);
Ao aprovar/mudar status do pedido registrarAuditoria('aprovar_pedido', `Status: ${novoStatus} - Pedido ${code}`);
saveMovement() ou similar registrarAuditoria('movimentacao_estoque', `${tipo} de ${produto} em ${casa}`);
deleteProduct() registrarAuditoria('excluir_produto', `Produto "${nome}" removido`);
saveCat() (salvar categoria) registrarAuditoria('salvar_categoria', `Categoria "${nome}" salva`);

7️⃣ Atualizar a função goPage()

Adicione os casos para as novas páginas
Procure a função goPage(page) no index.html. Dentro dela, há uma série de if (page === '...') ou um switch. Adicione estes casos:
// Dentro da função goPage(page), adicione:
if (page === 'audit-log') {
  initAuditLogPage();
}
if (page === 'bi') {
  initBI();
}

✅ Checklist final — verifique tudo

Antes de publicar, confirme cada item:
  • Os arquivos lumen-rbac.js e lumen-bi.js estão na mesma pasta do index.html
  • As 2 tags <script src="..."> foram adicionadas antes do </body>
  • await inicializarRBAC(user.uid) foi adicionado após o login
  • As Regras do Firestore foram publicadas no Firebase Console
  • Pelo menos 1 usuário tem perfil admin em usuarios_perfis
  • As páginas de Audit Log e BI foram adicionadas no HTML
  • Os itens de menu foram adicionados na sidebar
  • Os casos audit-log e bi foram adicionados na função goPage()
🎉
Tudo pronto! Após publicar, faça login como admin e você verá o badge de perfil na topbar, os novos itens no menu lateral, e poderá acessar o Log de Auditoria e os Relatórios BI.
⚠️
Problema? Abra o navegador, aperte F12, vá na aba "Console". Qualquer erro aparece em vermelho lá. Os erros mais comuns são: arquivo .js não encontrado (verifique o nome e localização), ou usuário sem documento em usuarios_perfis (crie o documento conforme o Passo 4).
